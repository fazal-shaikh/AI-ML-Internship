# Task 8 – Clustering with K-Means

## Objective
To perform unsupervised learning using K-Means clustering.

## Dataset
Mall Customers Dataset

## Steps Performed
- Loaded and visualized dataset
- Selected relevant features
- Applied feature scaling
- Used Elbow Method to determine optimal K
- Applied K-Means clustering
- Visualized clusters
- Evaluated using Silhouette Score

## Key Concepts Learned
- K-Means clustering
- Inertia and Elbow Method
- Cluster visualization
- Silhouette Score evaluation
- Difference between clustering and classification

## Final Summary
K-Means clustering successfully grouped customers into meaningful segments.
The Elbow Method and Silhouette Score were used to evaluate model performance.
This task demonstrates practical application of unsupervised learning for business insights.
