# Task 7 – Support Vector Machines (SVM)

## Objective
To implement SVM for linear and non-linear classification.

## Dataset
Breast Cancer Dataset

## Steps Performed
- Preprocessed dataset for binary classification
- Applied feature scaling
- Trained Linear and RBF SVM models
- Tuned hyperparameters (C, gamma)
- Evaluated using accuracy & cross-validation
- Visualized decision boundary

## Key Learnings
- SVM maximizes margin between classes
- Linear kernel for simple separation
- RBF kernel for complex patterns
- C controls regularization
- Gamma controls decision boundary complexity

## Outcome
Successfully implemented and compared linear and non-linear SVM models.
