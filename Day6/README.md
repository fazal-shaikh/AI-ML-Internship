# Task 6 – K-Nearest Neighbors (KNN) Classification

## Objective
To implement and understand the KNN algorithm for classification problems.

## Dataset
Iris Dataset

## Steps Performed
- Normalized features using StandardScaler
- Trained KNeighborsClassifier
- Tested different K values
- Evaluated using accuracy and confusion matrix
- Visualized decision boundaries

## Key Learnings
- KNN is distance-based and instance-based learning
- Normalization is crucial
- Small K may overfit, large K may underfit
- Decision boundaries help understand classification regions

## Outcome
Successfully implemented KNN classifier and evaluated model performance.
