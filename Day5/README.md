# Task 5 – Decision Trees and Random Forests

## Objective
To implement tree-based classification models and understand ensemble learning.

## Dataset
Heart Disease Dataset

## Steps Performed
- Trained Decision Tree classifier
- Visualized the decision tree
- Controlled overfitting using max_depth
- Trained Random Forest model
- Compared accuracy between models
- Analyzed feature importance
- Evaluated performance using cross-validation

## Key Learnings
- Decision trees split data using Gini/Entropy.
- Deep trees may overfit.
- Random Forest reduces overfitting using bagging.
- Feature importance helps identify influential variables.

## Outcome
Successfully built and compared tree-based models for classification.
